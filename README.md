# Super Flip

霓虹风格的弹球折射街机小游戏。从屏幕顶部向下发射弹球，让弹球在能量球之间反弹，用有限的射击次数清空每一关的目标。

## 运行

无任何依赖，直接启动本地静态服务：

```bash
npm start
```

然后打开 http://localhost:4321

## 玩法

- 点击 / 触屏瞄准，轨迹预览会显示反弹路线
- 每关固定 5 次射击：点一次自动打光当前弹药，弹球全部落出屏幕后才能再次射击
- 弹球命中能量球会造成伤害并反弹；一轮射击的所有弹球落出屏幕后，弹药才会回满
- 目标有圆形、方形、三角、菱形、六边形等形状，形状不同耐久也不同：三角形最耐打，菱形最小、耐久最低但移动更快
- 每关最多只有 2 个目标会移动
- 琥珀色补给球一击破碎，之后每轮发射的弹药 +2
- 随着波次提升，目标数量与耐久都会增加
- 清空所有目标即可过关；5 次射击用完仍有目标残留则游戏结束
